# Perfil de referencia (Baseline Profile) escrito a mano.
# AGP lo compila a assets/dexopt/baseline.prof en release y androidx.profileinstaller lo aplica al instalar,
# así ART precompila (AOT) estas rutas y el primer arranque / primer desplazamiento no se interpretan ni
# compilan con JIT sobre la marcha (la causa principal de jank en el primer uso en un Cortex-A53).
#
# Formato: [H]ot [S]tartup [P]ost-startup + firma; ** = comodín.
#
# Criterio:
#  - S (startup) SOLO para lo que corre antes del primer frame de Inicio: así el layout del dex de arranque
#    sigue agrupando lo realmente necesario y no se diluye.
#  - No se repiten librerías que ya traen su propio perfil dentro del AAR (Compose runtime/ui/foundation/
#    material3/animation, navigation, lifecycle, activity, core, splashscreen, CameraX, corrutinas): AGP los
#    fusiona solo. Marcarlas aquí con comodines compilaba casi todo (≈ "speed"), alargaba la instalación y
#    añadía decenas de MB de odex.
#  - Lo ideal es regenerarlo con BaselineProfileGenerator (Macrobenchmark) en un dispositivo real.
